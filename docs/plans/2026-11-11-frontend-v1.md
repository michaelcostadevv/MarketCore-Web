# MarketCore Web v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Frontend React da loja MarketCore consumindo a API Spring em `http://localhost:8080`.

**Architecture:** SPA Vite. Páginas → hooks TanStack Query → funções de `src/api/` → `client.ts` (fetch + token + `ApiError`). Auth e carrinho em Contexts persistidos no `localStorage`.

**Tech Stack:** Vite (react-ts), React 19, TypeScript, React Router 7 (`react-router`), TanStack Query 5, Tailwind 4 (`@tailwindcss/vite`), Vitest + Testing Library + jsdom.

**Spec:** `docs/specs/2026-11-11-frontend-v1-design.md`

## Global Constraints

- Node 24 no CI; `npm ci` precisa funcionar (commitar `package-lock.json`).
- Scripts obrigatórios: `lint`, `typecheck` (`tsc -b`), `test` (`vitest run`), `build`.
- `VITE_API_URL` com padrão `http://localhost:8080`; dev server na porta **5173** (CORS da API).
- Paginação da API: `{ content: T[], page: { size, number, totalElements, totalPages } }`.
- Erro da API: `{ timestamp, status, erro, mensagem, caminho, detalhes: string[] }`.
- Textos da UI e commits em português; commits `tipo: descrição` + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Um PR por tema; PRs 4 e 5 só depois do merge do anterior.

## Review Focus

- API desligada (`fetch` rejeita): telas mostram "Não foi possível conectar à API", não tela branca. → teste em Task 3.
- Resposta de erro sem corpo JSON (ex.: 403 vazio, HTML de proxy): `ApiError` com mensagem genérica. → teste em Task 3.
- `imagemUrl` nula: card mostra placeholder, não `<img src="null">`. → teste em Task 3.
- Busca vazia sem resultados: estado "Nenhum produto encontrado". → teste em Task 3.
- Quantidade no carrinho acima do estoque ou < 1: limitada a `1..quantidade`. → teste em Task 5.

## Decisões tomadas durante a execução

- **Task 1: Vite 7 em vez de Vite 8.** O Smart App Control do Windows bloqueia o binário nativo do Rolldown (Vite 8); a alternativa WASM não resolve caminhos no Windows. Vite 7 + `@vitejs/plugin-react` 5 + Tailwind 4 + Vitest foram testados e funcionam. Custo se errado: `npm i vite@8` no futuro.
- **Task 1: oxlint em vez de ESLint.** É o linter que o template atual do Vite traz (`.oxlintrc.json`). O script `lint` continua com o mesmo nome. Custo se errado: trocar o script.
